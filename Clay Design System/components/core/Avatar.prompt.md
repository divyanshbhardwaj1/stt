Clay circular avatar — use in testimonial cards, expert cards, and account menus. Falls back to brand-tinted initials when no image.

```jsx
<Avatar name="Mei Lin" src="/people/mei.jpg" size={48} />
<Avatar name="Devon Rao" tone="peach" />
```

`tone` (lavender/peach/mint/ochre/teal) only applies to the initials fallback.
