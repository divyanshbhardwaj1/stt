Clay pill badge — use for category labels, "New" tags, status chips, and uppercase section eyebrows.

```jsx
<Badge>New</Badge>
<Badge tone="pink">Outbound</Badge>
<Badge uppercase>Featured</Badge>
```

`tone`: cream (default), pink, teal, lavender, peach, ochre, success, warning, error. Set `uppercase` for the 12px wide-tracked eyebrow style used above section headlines.
