Clay single-line text input — use in forms, sign-up bands, and demo-request modals; cream fill with a hairline that thickens to ink on focus.

```jsx
<Input label="Work email" placeholder="you@company.com" type="email" />
<Input label="Seats" hint="You can change this later" />
<Input label="Work email" error="Enter a valid email" />
```

Props: `label`, `hint`, `error` (red border + message, overrides hint), `type`, `disabled`. 44px tall, 12px radius.
